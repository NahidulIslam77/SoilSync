# 🌱 SoilSync – Smart Agricultural Data Platform

A comprehensive web-based agricultural management platform that helps farmers make data-driven decisions through crop recommendations, pest and disease management, expert consultation, market monitoring, irrigation planning, and multilingual support.

Developed as an academic project using **PHP**, **MySQL**, **HTML**, **CSS**, **Bootstrap**, and **JavaScript**.

## ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/NahidulIslam77/SoilSync.git
```

### Move to XAMPP

```
htdocs/SoilSync
```

### Import Database

Import

```
soilsync.sql
```

using phpMyAdmin.

### Configure Database

Open

```
db.php
```

and update your database credentials if needed.

### Start Server

Start

- Apache
- MySQL

Visit

```
http://localhost/SoilSync
```
